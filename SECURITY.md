# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub Security Advisories or by emailing security@example.invalid.

We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution.

## Supported Versions

We provide security updates for the latest stable release.

## Scope

This policy covers the Personal AI repository and its dependencies.

## Disclosure Policy

We follow coordinated disclosure practices. Public disclosure will occur after a fix is released.

## Thank You

Thank you for helping keep Personal AI secure.
